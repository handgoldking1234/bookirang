# 북이랑 (Bookirang)

책 한 쪽을 찍으면 AI 튜터 도란이와 영어로 북토킹하는 초등 교육 앱의 프로토타입입니다.

- `index.html` 하나로 동작하는 정적 퍼블리싱 파일입니다 (순수 마크업 + 간단한 스크립트).
- PC에서는 휴대폰 크기로, 휴대폰과 태블릿에서는 전체 화면으로 보입니다.
- 화면: 홈, 책 찍기, 내용 확인, 북토킹, 완료, 리포트(요약·단어 분석·교정), 다시 말하기, 2주 14권 추천, 성장 통계, 랭킹(리더보드·마일스톤·명예의 전당), 책장
- 모든 숫자와 아이 이름은 프로토타입용 샘플 데이터입니다.

## 실행

`index.html`을 브라우저로 열거나, Vercel 등에 정적 사이트로 배포하면 됩니다.
